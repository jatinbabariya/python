## Install VENV plugin

```bash
pip install virtualenv
```

or

```bash
pip3 install virtualenv
```

> ## Create venv folder

```bash
python -m venv .venv
```

- for windows

  - .venv/Scripts/activate.bat

- for linux/mac

  - .vnev/bin/activate
